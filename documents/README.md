# Where to drop PDFs

## The short version

```
documents/<Country-Name>/<any-filename>.pdf
```

Then run:

```bash
node scripts/build-documents.mjs
```

That's it. The document appears in that country's drawer on the map. No code
changes, no manifest editing by hand.

---

## The rules

**Folder name = the country name, with hyphens for spaces.**
`documents/Burkina-Faso/`, `documents/Sierra-Leone/`, `documents/Kenya/`

Use the same spelling the atlas uses. `Ivory Coast`, `The Gambia`,
`Republic of the Congo` and `Democratic Republic of the Congo` all work — the
resolver knows the aliases. If a folder name doesn't resolve, the build script
**fails loudly and names the folder**, so a typo can't silently hide documents.
Create the folder if it doesn't exist yet.

**Filename can be anything.** It becomes the document's starting title, with
dashes turned into spaces. `decret-2011-311-motos-taxis.pdf` becomes
"Decret 2011 311 Motos Taxis" — readable, but see *Better titles* below.

**PDFs are preferred, but any file type works** (`.pdf`, `.html`, `.docx`, …).
The type is shown next to the title so nobody mistakes a saved news article for
legislation.

## Bad captures are refused, not shown

Scrapers sometimes save a Cloudflare bot-challenge or a "please enable
JavaScript" stub with a cheerful HTTP 200. One 3 KB *Client Challenge* page was
captured seven times and would have appeared as the road code of Cameroon, Cape
Verde, Chad, Gabon, Ivory Coast and Niger.

The build script refuses any capture that is both near-empty and carries a
challenge/error marker, and reports each one. The country's Source citation still
links out — only the bogus local copy is withheld.

To delete the refused files:

```bash
node scripts/build-documents.mjs --prune
```

This records the verdict in `data/inventory.json` (status `bot_challenge`, with
the reason) **before** deleting, so `documents-sources.csv` keeps showing that
source with no local copy and a stated cause. A gap should read as a known
outcome, never as work nobody attempted. Because the status is no longer `ok`,
`download_sources.py --retry-failed` will try those URLs again later — the block
may be temporary.

Byte-identical captures of one instrument under two URL forms are deduplicated
too, so a law is never listed twice.

## Better titles, languages, years

Titles come from, in order of preference:

1. **A human's wording** in `data/documents.json` (see below)
2. **The sheet's own citation** for that URL, matched automatically
3. **The filename**, as a last resort

Right now (2) yields almost nothing: of 235 source entries with a URL in the
sheet, **221 are bare URLs with no citation**, so only one document gets a real
title this way. This improves on its own as those citations get filled in — which
[SOURCES.md](../SOURCES.md) §7 already flags as the priority. Every citation
added to the sheet upgrades a document title here for free.

To set a title by hand, edit `data/documents.json` and set `titleEdited: true`:

```json
{
  "path": "documents/Burkina-Faso/36-securite-des-transports-b8bc9d95.pdf",
  "title": "Décret n°2011-311/PRES/PM/MTPEN (Burkina Faso, 2011)",
  "titleEdited": true,
  "language": "fr",
  "year": "2011"
}
```

`titleEdited: true` is what protects your wording from being overwritten the
next time the build script runs. `language` and `year` are always preserved.

## Large files

GitHub Pages serves individual files up to 100 MB, so most legislation is fine
as-is. Originals are kept uncompressed on purpose: for a regulator the PDF *is*
the primary source, and recompression is a lossy round-trip.

Above 10 MB, compress:

```bash
python scripts/compress_pdfs.py --dry-run   # see what would happen
python scripts/compress_pdfs.py             # actually do it
```

It only touches files over the threshold, tries lossless first, and keeps the
original alongside as `<name>.original.pdf`. Scanned PDFs get lossless treatment
only — for those the images *are* the text. Delete the `.original.pdf` files once
you're happy with the result.

## If we lose these files

`data/documents-sources.csv` is the ledger of every original URL we know of —
including sources that failed to download and ones we hold no copy of. It is
regenerated by `build-documents.mjs` from `data/inventory.json`, and it means the
`documents/` tree is replaceable rather than precious.

To re-fetch everything from the master sheet's Source column:

```bash
python scripts/extract_sources.py     # sheet -> data/sources.json
python scripts/download_sources.py    # fetch all, populate documents/
node scripts/build-documents.mjs      # rebuild the manifest
```

`download_sources.py` is idempotent — it skips anything already fetched
successfully, so it's safe to re-run. `--retry-failed` re-attempts only the
failures.

**Currently 122 source URLs are known and 5 have been downloaded** (the script
was last run as a `--limit 5` smoke test). Running it without `--limit` fetches
the rest.
